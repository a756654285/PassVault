# PassVault

一个**完全离线**的本地密码保险库，Windows 免安装桌面版。数据用你的主密码加密后只存在本机，不联网、不上传、无账号、无遥测。

作者：[@a756654285](https://github.com/a756654285) · 源码与问题反馈：https://github.com/a756654285/PassVault

> 基于 Electron + Web Crypto，单页界面 + 一个加密文件，没有服务端、没有数据库服务、没有云同步。

## 特性

- **本地加密**：PBKDF2-SHA256（25 万次迭代）派生密钥，AES-GCM 256 加密每条记录
- **自动保存**：新增 / 编辑 / 删除 / 拖动后停顿约 0.6 秒自动加密落盘，重开软件自动恢复
- **分组管理**：分组栏可拖动排序，列表条目可拖动排序，顺序随库一起加密保存
- **完整迁移**：「数据库迁移」导出完整备份（含分组顺序），另一台电脑一键导入，支持不同主密码、覆盖或合并
- **远程连接**：条目可记录 RDP / SSH / Telnet 主机，一键拉起 mstsc、SecureCRT 或系统终端
- **🔑 一键登录**（v1.1.0 新增）：有网址 + 密码的条目点一下，在独立隔离窗口打开网页并自动填入账号密码。**只填不提交**，最后一步由你本人确认；验证码 / 二次验证需手动完成
- **智能识别网址协议**（v1.1.1 新增）：填裸域名保存时自动判断协议——公网域名补 `https://`，本机 / 内网地址（`192.168.*`、`10.*`、`localhost`、`*.local` 等）补 `http://`；显式写入的协议始终优先。保存、打开、一键登录三处规则一致
- **分组下拉选择**（v1.1.1 新增）：新增 / 编辑条目时「分组」改为下拉框，直接选已有分组，无需手输；选「＋ 输入新分组…」仍可创建新分组
- **🔐 加密分享**（v1.1.2 新增）：分享需先输入主密码确认，再由你设置「文件打开密码」，生成自解密的加密 `.html` 文件——对方用浏览器打开、输密码才能查看，支持复制 / 另存 Word / 打印。两层密码都不写入文件
- **⏳ 分享有效期**（v1.1.2 新增，2026-11-28 升级为首次打开起算）：可选 1 / 3 / 7 / 30 天或永久，默认 7 天；**从对方首次打开分享文件/链接那一刻开始倒计时**，不是从你生成时开始。本机记录时间锚点，之后把系统时间往回调不会重置倒计时；到期字段用 AES-GCM 绑定防篡改
- **⏻ 关闭可最小化到托盘**（v1.1.3 新增）：点右上角 X 弹出主题化确认框，可选「最小化到托盘」（右下角绿色锁图标，单击/双击恢复，右键显示或退出）或「退出软件」；确认框居中、可用鼠标拖动
- **完全离线**：云同步功能已停用，软件运行时不发起任何网络请求

## 下载与运行

适用系统：**64 位 Windows 10 / 11**（目前只提供 win32-x64 版本）。

从 [Releases · v1.1.3](https://github.com/a756654285/PassVault/releases/tag/v1.1.3) 下载 `PassVault-v1.1.3-win64.zip`，**解压整个文件夹**后双击 `PassVault.exe`。

首次运行时 Windows 可能提示「Windows 已保护你的电脑」（未购买代码签名证书）：点「更多信息」→「仍要运行」。可先用 `SHA256SUMS.txt` 校验文件完整性：

```powershell
Get-FileHash .\PassVault-v1.1.3-win64.zip -Algorithm SHA256
```

v1.1.3 的正确值（与 Release 附件 `SHA256SUMS.txt` 一致）：

```
6267c3af01fbadc394876ab35680829ebd03a6171224c6e081b9d9a501073051
```

首次输入的**主密码即创建保险库**，请务必牢记 —— 主密码不上传、不缓存、不可找回，开发者也无法解密你的数据。

## 关于分享有效期

加密分享文件可设有效期（默认 7 天）。**倒计时从对方第一次打开该文件/链接时开始**（不是从生成时开始），本机记录首开时间锚点；到期后显示「此分享已过期」，无法查看。有效期时长固化在文件内并参与 AES-GCM 认证，篡改该字段会导致解密失败。

**防时钟回拨**：查看器只允许时间前进（取 `max(当前系统时间, 上次记录时间)`），所以到期后把系统时间往回调不会重置倒计时，仍按到期处理。

请理解这仍是**离线文件**的能力边界：没有服务器，无法真正「远程失效」。对方在**第一次打开之前**就把系统时间调到未来、或删除本机记录（清浏览器缓存 / 小程序存储）、或到期前留存内容副本，仍然可以绕过。它适合限制「正常接收方过期后打不开 + 到期后改时间」，不适合对抗蓄意绕过。需要强失效请改用在线分享服务。

## 数据在哪里

| 场景 | 位置 |
|---|---|
| 绿色版（默认） | 软件同目录 `数据库\autosave.vault` |
| 安装在无写权限目录 | `%APPDATA%\PassVault\数据库\autosave.vault` |

备份 = 复制整个 `数据库` 文件夹，或用「💽 数据库迁移」导出 `.vault`。**转发软件给别人时必须排除 `数据库` 文件夹**，里面是你的真实密码。升级软件直接替换程序文件即可，升级前先备份该文件夹。

更详细的使用说明见 [使用说明.txt](使用说明.txt)。

## 从源码运行 / 自行构建

需要 Node.js 16+：

```bash
npm install
npm start          # 开发模式运行
npm run pack       # 打包到 ./dist（electron-packager）
```

打 Release 包（会硬性拦截 `数据库` 文件夹与 `.vault` 文件，防止真实密码被打包）：

```bash
python scripts/build_release.py --version 1.1.3 --source <成品目录> --outdir <输出目录>
```

不带参数时默认读 `dist/PassVault-win32-x64`、输出到 `dist/release`。

目录结构：

```
main.js            Electron 主进程：窗口/托盘、本地文件读写、RDP/终端调用
preload.js         contextBridge 安全桥接
tray.ico           系统托盘图标（绿色锁）
app/PassVault.html 单页界面 + 加解密逻辑（Web Crypto）
package.json       构建脚本
scripts/           Release 打包与校验脚本
```

## 安全说明

**设计上的保证**

- 密钥只在内存中，主密码不明文落盘；每条记录独立随机 IV，AES-GCM 认证加密
- 认证材料与加密密钥使用不同派生参数；服务端（已停用）即便存在也只拿到密文
- 无网络请求、无遥测、无第三方 SDK、无自动更新
- 加密分享的密码、有效期字段均不写入明文；有效期时长参与 AES-GCM 认证，改字段续期会导致解密失败
- 分享有效期从对方**首次打开起算**，查看器只允许时间前进，到期后改系统时间回拨不会重置倒计时

**使用前请了解的局限**

- 主密码**不可找回、不提供重置**，遗忘即永久失去数据
- 无闲置自动锁定，离开电脑请手动点「🔒 锁定」
- 复制密码后剪贴板不会自动清空
- 「加密分享」受你设置的打开密码保护，有效期从首次打开起算、到期后改系统时间回拨无效；但**离线方案无法彻底防绕过**：对方在首次打开前把系统时间调到未来、清除本机时间记录（浏览器缓存 / 小程序存储）、或到期前留存明文副本，仍可继续查看。要真正强制失效 / 远程撤回需联网服务器控制，本项目不提供
- 数据文件权限依赖所在目录的 Windows 权限，建议不要放在多人可读的共享目录
- **本项目未经独立第三方安全审计**，请自行评估是否用于高敏感场景

如发现安全问题，请通过 GitHub 私有安全通告（Security Advisories）报告，不要直接开公开 Issue。
