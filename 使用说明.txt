================================================================
        PassVault 密码保险库 · 免安装桌面版  v1.1.3
================================================================

【这是什么】
一个完全离线的本地账号密码管理软件。数据用你的主密码
（PBKDF2 25 万次 + AES-GCM 256）加密后只存在本机，
不联网、不上传、无账号、无遥测。开发者也无法查看或找回。

【第一次使用】
1. 解压整个文件夹到任意位置（不要只拷 PassVault.exe）。
2. 双击 PassVault.exe。首次运行 Windows 可能提示
   "Windows 已保护你的电脑"：点「更多信息」→「仍要运行」。
3. 输入一个主密码即创建保险库，以后每次打开都用它解锁。
   * 主密码忘了谁都解不开（包括开发者），务必牢记。

【数据存在哪 / 自动保存】
- 默认在软件同目录的「数据库\autosave.vault」；
  若装在无写权限的目录，则改存 %APPDATA%\PassVault\数据库\。
- 新增 / 编辑 / 删除 / 拖动后停顿约 0.6 秒自动加密写盘，
  关掉软件再打开自动恢复，不用每次点「保存」。
- 备份 = 复制整个「数据库」文件夹，或用「数据库迁移」导出。
- * 打包或转发软件给别人时，务必排除「数据库」文件夹，
    里面是你的真实密码。

【常用功能】
- ＋ 新增：标题 / 账号 / 密码（默认隐藏，点眼睛图标显示）/
  网址 / 分组 / 备注；也可记录 RDP 远程桌面、SSH / Telnet
  终端的主机与账号。
- 搜索框：按标题 / 账号 / 网址 / 备注 / 主机过滤。
- 分组栏在搜索框下方：「全部分组」固定在最左，其余分组
  按住左侧把手可拖动排序；列表条目也能拖动调整顺序。
- 条目按钮：显示密码、复制账号 / 密码、编辑、删除、
  打开网址（以 \\ 开头的共享文件夹用资源管理器打开）、
  一键登录、分享该条目、远程连接（RDP / SSH / Telnet）。
- 【v1.1.0 新增】🔑 一键登录：条目有网址和密码时显示该按钮，
  点击后弹出独立隔离窗口打开网页并自动填入账号密码，省去手工输入。
  * 只填不提交，最后一步由你本人点确认；验证码 / 二次验证需手动完成。
  * 网址没写 https:// 也能用（自动补全）；以 \\ 开头的共享路径不支持。
  * 账号密码只在内存里经内部通道传一次，不写文件、不进剪贴板、
    不拼进网址；关闭窗口即清除该窗口的临时数据。
  * 复杂登录页（ iframe 深层表单、多步跳转）可能填不全，需手动补填。
- 分享：需先输入保险库主密码确认（第一层保护）；再自行设置一个
  「文件打开密码」，生成加密分享文件 .html（第二层保护）。
  * 对方用浏览器打开该文件、输入你告知的打开密码才能看到内容；
    查看器支持复制、另存为 Word、打印。
  * 双重加密：保险库主密码确认分享 + 你设的打开密码保护文件，
    两层密码都不写入文件；忘记打开密码则谁都打不开。
  * 打开密码请通过另一个渠道告知对方，不要和文件一起发。
  * 【有效期】生成时可选 1/3/7/30 天或永久，默认 7 天。倒计时从对方
    「首次打开该文件/链接」那一刻开始（不是从生成时开始）；对方本机记录
    首开时间锚点，之后只允许时间前进，到期后把电脑系统时间往回调不会
    重置倒计时，仍显示「此分享已过期」。有效期时长固化在文件里并参与
    AES-GCM 认证，改字段会导致解密失败。
    注意：这仍是离线方案——对方在首次打开前调时间、清本机记录（浏览器
    缓存/小程序存储）或到期前留存内容副本仍可绕过；要真正强制失效需联网
    由服务器控制，本离线软件不提供该能力。

- 【v1.1.3 更新】关闭窗口改为询问：点右上角 X 弹主题化窗口，可选「最小化到托盘」（右下角绿色锁图标，单击/双击恢复，右键可显示或退出）或「退出软件」；弹窗居中且可鼠标拖动。
- 【v1.1.2 更新】加密分享（双密码保护）：分享需保险库主密码确认，
  再由你设置「文件打开密码」，生成自解密的加密 .html 文件，对方输密码查看。
  支持有效期（1/3/7/30 天或永久，默认 7 天），到期后文件无法查看。
  分享按钮简化为一步：设好密码点「生成并分享」即完成并自动关闭。
- 【关闭行为】点右上角 X 会弹窗询问：
  * 最小化到托盘：程序缩到屏幕右下角托盘区(绿色锁图标)，双击/单击图标恢复窗口；
    右键图标可「显示主窗口」或「退出 PassVault」。
  * 退出软件：完全关闭程序(数据已自动保存)。
  * 取消：返回窗口，不做任何操作。
- 【v1.1.1 更新】分组改为下拉选择：新增/编辑条目时点「分组」框
  直接从已有分组里选，不用手输；要建新分组选「＋ 输入新分组…」再填名字。
- 【v1.1.1 更新】网址自动识别协议：填裸域名保存时，公网域名自动补
  https://，本机/内网地址（192.168.*、10.*、localhost、*.local 等）
  自动补 http://；你自己写了 http:// 或 https:// 则以你的为准。
  打开网址和一键登录也按同样规则识别，三处保持一致。

【换电脑 / 备份迁移】
- 「💽 数据库迁移」→ 导出完整备份（.vault，含全部条目与分组顺序）。
- 新电脑打开软件 → 解锁页「📂 一键导入数据库」→ 选择文件 →
  输入该备份的主密码 → 选覆盖或合并。支持与原库不同的主密码。
- 「💾 保存保险库」也可导出当前加密库文件。
- 升级软件：直接替换程序文件即可，升级前先备份「数据库」文件夹。

【安全提醒】
- 主密码不可找回、不提供重置，请自行离线妥善保管。
- 软件完全离线运行，不发任何网络请求；云同步功能已停用。
- 复制密码后注意及时清理剪贴板；分享文件用毕及时删除。
