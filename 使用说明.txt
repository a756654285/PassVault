================================================================
        PassVault 密码保险库 · 免安装桌面版  v1.0.0
================================================================

【这是什么】
一个完全离线的本地账号密码管理软件。数据用你的主密码
（PBKDF2 25 万次 + AES-GCM 256）加密后只存在本机，
不联网、不上传、无账号、无遥测。开发者也无法查看或找回。

【第一次使用】
1. 解压整个文件夹到任意位置（不要只拷 PassVault.exe）。
2. 双击 PassVault.exe。首次运行 Windows 可能提示
   "Windows 已保护你的电脑"：点「更多信息」→「仍要运行」。
3. 输入一个主密码即创建保险库，以后每次打开都用它解锁。
   * 主密码忘了谁都解不开（包括开发者），务必牢记。

【数据存在哪 / 自动保存】
- 默认在软件同目录的「数据库\autosave.vault」；
  若装在无写权限的目录，则改存 %APPDATA%\PassVault\数据库\。
- 新增 / 编辑 / 删除 / 拖动后停顿约 0.6 秒自动加密写盘，
  关掉软件再打开自动恢复，不用每次点「保存」。
- 备份 = 复制整个「数据库」文件夹，或用「数据库迁移」导出。
- * 打包或转发软件给别人时，务必排除「数据库」文件夹，
    里面是你的真实密码。

【常用功能】
- ＋ 新增：标题 / 账号 / 密码（默认隐藏，点眼睛图标显示）/
  网址 / 分组 / 备注；也可记录 RDP 远程桌面、SSH / Telnet
  终端的主机与账号。
- 搜索框：按标题 / 账号 / 网址 / 备注 / 主机过滤。
- 分组栏在搜索框下方：「全部分组」固定在最左，其余分组
  按住左侧把手可拖动排序；列表条目也能拖动调整顺序。
- 条目按钮：显示密码、复制账号 / 密码、编辑、删除、
  打开网址（以 \\ 开头的共享文件夹用资源管理器打开）、
  分享该条目、远程连接（RDP / SSH / Telnet）。
- 分享：需先输入主密码确认，生成 .txt / Word 明文文件。
  * 文件内含明文密码，只通过可信渠道发送。

【换电脑 / 备份迁移】
- 「💽 数据库迁移」→ 导出完整备份（.vault，含全部条目与分组顺序）。
- 新电脑打开软件 → 解锁页「📂 一键导入数据库」→ 选择文件 →
  输入该备份的主密码 → 选覆盖或合并。支持与原库不同的主密码。
- 「💾 保存保险库」也可导出当前加密库文件。
- 升级软件：直接替换程序文件即可，升级前先备份「数据库」文件夹。

【安全提醒】
- 主密码不可找回、不提供重置，请自行离线妥善保管。
- 软件完全离线运行，不发任何网络请求；云同步功能已停用。
- 复制密码后注意及时清理剪贴板；分享文件用毕及时删除。
